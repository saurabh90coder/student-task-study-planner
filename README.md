# Student Task & Study Planner

A simple, responsive web application for students to organise assignments, study tasks, due dates and weekly study sessions.

## Features
- Dashboard showing total, completed and pending tasks
- Add tasks with subject, due date and priority
- Mark tasks as completed or delete them
- Search and filter tasks
- Weekly sample study timetable
- Progress percentage and progress bar
- Saves tasks in the browser with Local Storage

## Technologies
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` or open it in a browser.
4. Select **My Tasks** and click **New task**.

No installation or server is required.

## Project Objective
The project addresses the common problem of students forgetting assignments and deadlines by providing one simple digital workspace.

## Relation to the Subject
The project is inspired by productivity and organisation concepts covered in Notion and Airtable:
- Pages and sections are represented by Dashboard, Tasks, Timetable and Progress.
- Task details are organised as records and fields.
- Search and filters help users find tasks.
- The dashboard presents information in a workspace layout.

This is an independent web application. It does not connect to or modify a user's Notion or Airtable account.

## Future Scope
