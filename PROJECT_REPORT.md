# MINOR PROJECT REPORT
## Student Task & Study Planner

### 1. Introduction
Students often manage assignments, study schedules and deadlines in different places. This can lead to missed submissions and poor time management. The Student Task & Study Planner is a simple digital workspace that brings these activities together.

### 2. Problem Statement
Students may forget assignment deadlines or find it difficult to track completed and pending work. A simple and organised task management system can help them plan academic activities.

### 3. Objectives
- Provide one place for managing academic tasks.
- Record task title, subject, due date and priority.
- Help students identify pending and completed work.
- Display a weekly study timetable.
- Show overall task completion progress.

### 4. Scope
The application is designed for individual students. It runs in a web browser and stores task information locally on the same browser using Local Storage.

### 5. Tools and Technologies
- HTML: creates the structure of the application.
- CSS: provides layout, colours and responsive design.
- JavaScript: handles task operations, filters and calculations.
- Local Storage: saves tasks in the browser.

### 6. Main Modules
1. Dashboard: displays task statistics and upcoming tasks.
2. My Tasks: allows adding, deleting and completing tasks.
3. Study Timetable: displays a sample weekly study routine.
4. Progress: displays completed tasks and completion percentage.

### 7. Working
The user opens the application in a browser and adds a task with its title, category, due date and priority. JavaScript stores the task in Local Storage. The dashboard and progress section update automatically. The user can search, filter, complete or delete tasks.

### 8. Advantages
- Easy to use.
- No software installation or account required.
- Helps organise academic work.
- Works on desktop and mobile screens.
- Task data remains saved in the same browser.

### 9. Limitations
- Data is stored only in the current browser.
- There is no multi-user login or cloud synchronisation.
- Automatic reminders are not included.

### 10. Future Enhancements
- Add login and cloud database.
- Add automatic deadline notifications.
- Add AI-based study suggestions.
- Connect with Notion or Airtable.

### 11. Conclusion
The Student Task & Study Planner provides a simple solution for organising student tasks and study schedules. It demonstrates the use of web technologies and productivity-management concepts in a practical project.
